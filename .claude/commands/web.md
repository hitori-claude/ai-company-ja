作りたいもの: $ARGUMENTS

Web班でサイトを作ってください。

1. 次の4つを社長に**1つずつ**聞いて `brief.md` にまとめる：①どんなサイトか ②載せたい情報 ③参考サイト（なくてもよい）④見た目の希望
2. `outputs/web/今日の日付_名前/` を作り、brief.md を置く
3. `web-planner` → `web-designer` → `web-builder` → `web-checker` の順に頼む
4. check.md に「直す」があれば `web-builder` に直してもらい、もう一度 `web-checker`（最大2回）
5. 社長に site/index.html のパスを伝える

共通の最後の手順：
- 社員がファイルを書けなかったときは、返ってきた内容を司令塔がそのファイルに保存する
- `memory/changes.md` に「日付・作ったもの・パス」を1行足す
