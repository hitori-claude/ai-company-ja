note班で記事を1本作ってください。

1. テーマが空なら、社長に「何について書きますか？」とだけ聞く
2. `outputs/note/今日の日付_テーマ/` を作る
3. `note-researcher` → `note-planner` → `note-writer` の順に頼む。前の社員の成果物のパスを次に渡す
4. 司令塔が article.md を読んで、structure.md の約束が守られているか確かめる
5. 社長に、3つのファイルのパスと【社長の実例】を埋める所の数を伝える

- 社員がファイルを書けなかったときは、返ってきた内容を司令塔がそのファイルに保存する
- `memory/changes.md` に「日付・作ったもの・パス」を1行足す
